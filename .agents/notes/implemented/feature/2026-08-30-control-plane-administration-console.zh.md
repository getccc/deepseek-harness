# Agent Note: Control Plane 管理其网关所强制执行的对象

Status: implemented

[English](2026-08-30-control-plane-administration-console.md) | 中文

## 问题

Team Edition 已经存储账户、角色、授权、设备和公司模型，但如果管理员必须调用服务方法或检查 SQLite 才能改变这些记录，它们还不是可用的产品。最初的 Team Shell 页面只在无样式表格中暴露成员、角色名称和设备。组织身份、角色内部的权限、成员绑定和模型目录仍不可见，这会让已部署的 RBAC 系统看起来像不存在，并鼓励绕过产品所要证明的同一授权与审计路径进行带外编辑。

## 决策

[浏览器应用那篇 Agent Note](../architecture/2026-08-30-administration-console-as-a-browser-application.zh.md)拥有展示方式：管理是一个建立在 JSON API 之上的 React 与 Ant Design 应用，而 `dsh-team-shell` 只拥有设备确认页。常驻导航通向总览、部门、用户、角色、菜单与模型。用户的可展开行承载该用户的设备清单与撤销操作，而不是使用独立设备页面。

管理 API 为组织、成员、角色、设备和模型目录管理注册受治理的控制资源。只有持有 `organization.admin.access` 的账户才能在密码认证后创建管理 Session；读取与写入路由随后会在动作不同时询问不同的代码注册权限。部署在控制台之外引导首位管理员，随后该管理员通过 `PERMISSION_CATALOG` 组合角色、把角色绑定到用户或解除绑定、配置账户密码、通过账户级会话与设备撤销来替换密码，并通过受审计的写入管理组织、设备与模型记录。

角色页读取类型授权与资源授权。它的权限与导航编辑器为组织范围操作创建类型授权。它的模型资源编辑器把目录模型解析为托管资源 id，并为所选模型写入精确的 `model.discover` 与 `model.invoke` 授权，因此 Runner 的模型目录会服从角色，而无需授予全部模型。

模型页只存储模型网关的目录字段。凭据字段是服务端凭据引用，而不是密钥材料；Runner 仍只会通过发现流程收到稳定模型引用与显示名。

凭据引用与凭据键寻址的是不同的东西，只有引用能在网关发起调用时解析。控制台与目录各自拒绝不是引用的取值，因此注册会在管理员键入处失败，而不是等到首次调用一个目录读作 active 的模型时才失败。

Session 答复带着本部署的密码策略，控制台在密码框被键入时就据此检查新密码。若控制台自持一份要求的副本，它说出的规则可能并非 Control Plane 所持有；而事后的拒绝只能告诉管理员出了问题。Control Plane 仍会对送达的内容施加该策略。

用户页按组织架构本身收窄：公司在根，部门嵌套其下，公司之上没有别的行。选中公司即选中全部人员，选中一个部门会连同其下级部门一起带上。

管理页面或动作失败时，答复说明这是站点的失败。没有这条答复，Web 服务器自带的兜底会回一个空的 400，等于告诉已登录的管理员他们的请求格式有误，而实际无法服务的是站点自身。

## 曾考虑的替代方案

**单独的 SPA 管理应用。** 已否决，因为它会为一个在任何应用包加载前就能工作的界面增加第二套客户端包、API 和授权展示。首批管理工作流需要的是表单与表格，而不是客户端运行时。

**只为既有三个页面加样式。** 已否决，因为外观会改善，但组织、授权、成员角色绑定和公司模型仍然不可见。缺失的信息架构才是产品缺陷。

**让管理角色成为万能钥匙。** 已否决，因为管理账户不应隐含模型调用或知识库访问权。控制台展示并编辑显式授权；它不会在既有的仅 Allow 并集之外加入权限继承。

**在控制台里重述密码要求。** 已否决，因为该要求由部署配置，数字多一份副本就多一处要改的地方。控制台读取 Control Plane 的答复。

**让页面接受任意权限字符串。** 已否决，因为封闭目录正是让拼写错误在写入授权处失败的机制。表单只提交目录组合，而服务会再次验证该组合。

## 后果

管理员可以看见 RBAC 已启用、检查某个角色为何准入工作，并在不离开产品的情况下管理当前 Control Plane 已实现的 Team Edition 资源。每次写入都保留与非 UI 调用方相同的审计轨迹和默认拒绝求值。

控制台面向当前单实例、单组织部署，并且不分页地渲染完整列表。用户组、模型以外的资源专属编辑器、知识目录、私有产物目录和生产 PostgreSQL 运维仍是独立能力，而不是伪装成可用管理页面的装饰性占位符。
