# Agent Note: The administration console is a browser application

Status: implemented

[English](2026-08-30-administration-console-as-a-browser-application.md) | 中文

取代[服务端渲染控制台那篇笔记](../feature/2026-08-30-control-plane-administration-console.zh.md)中的呈现决策；其中记录的受治理资源、每条路由所询问的权限，以及目录的各项拒绝，均未改变。

## 问题

服务端渲染的控制台走到了表单与整页刷新所能表达的尽头。每一次动作都是一次 POST 加一次重定向，因此停用一个成员和重命名一个组织，代价与重新加载页面相同；表格没有新地址就无法筛选；弹框根本不存在，于是创建成员与确认一次破坏性动作看起来一模一样。它的文案也只有英文并且嵌在标记里，不把每一页模板化就够不着第二种语言。

## 决策

管理是一个 React 与 Ant Design 应用，由 `apps/team-admin` 构建，并由 Control Plane 在 `/team/admin` 提供。它只与一样东西对话：`dsh-team-admin-api`——`/team/api` 之下的 JSON 界面，它在询问持有记录的那个服务之前，会先问与每次表单提交同样的三个问题（一个会话、本站的 `Origin`，以及该会话派生的 CSRF 值），并留下同样的审计记录。

**应用决定显示什么；它不决定什么是被允许的。** `GET /team/api/session` 回答该成员持有的 `resourceType|action` 对，好让没人能用的控件不必出现。随后每条路由仍会再问一次访问控制。一个显示了不该显示的按钮的构建，得到的依然是拒绝。

**每个集合都是一张表，每一次创建、编辑与破坏性动作都是一个弹框。** 一次写入以它改动的那份集合作答，因此表格从这个答复更新，而不是从一次已经落后一个往返的二次读取更新。

**文案由 locale 拥有，与浏览器客户端一致。** `zh` 是键集的事实源，`en` 与之对齐，因此一个键出现在一本词典而缺席于另一本，是类型错误而不是运行时的空白标签。这个选择属于这个浏览器，存在 `localStorage` 里：一台机器上的显示偏好不是组织替成员做的决定，Control Plane 也没有理由存它。

**可选浏览器 Handoff 仍使用服务端渲染确认页。** 组合 `dsh-team-shell` 的部署会让成员从自己 Runner 提供的链接抵达那里，以比对一个 Code 并按下一个按钮。默认 Control Plane 不组合该页面；普通成员改在自己的 Runner 上认证。可选页面与管理应用共享的 Session 规则仍位于 `dsh-team-browser-session`。

## 备选方案

**保留服务端渲染的控制台，只把样式改得像。** 在它被建成并使用之后被否决：外观是够得着的，但弹框确认、表格就地更新与第二种语言，各自都需要一个表单加重定向的页面所没有的机制，而这些机制加起来就是一个写得很糟的应用。

**用一个应用把确认页也覆盖掉。** 否决，因为那个页面的全部职责就是在一次跨站导航落地的瞬间即可阅读，而且它是唯一一个失败就意味着成员根本连不上电脑的页面。

**用另一个进程提供控制台。** 否决，因为 Control Plane 本来就终结着控制台运行其上的那个会话，第二个监听器意味着第二个地址、第二处 TLS 终结，以及必须跨两者划定作用域的 cookie。

**把语言偏好按账户存储。** 暂且否决：它是一项按浏览器的显示选择，要让它持久化就意味着一个账户字段、一条设置路由，以及一个关于成员在与之不一致的机器上该看到什么的决定。

## 后果

管理员在两种语言下都得到了一个管理控制台应有的交互，而其所依托的 API 独立于它执行强制。应用本身 34 kB，旁边是 963 kB 的 React 与 Ant Design vendor 分块，二者分开，因此改动一个视图只会让小的那块重新哈希。

Control Plane 现在提供一份构建产物，因此 `pnpm run build` 成了部署的前置条件，而此前不是。控制台没有客户端路由，因此浏览器刷新会回到概览，而不是当时打开的那个视图。入职、首个密码、针对具名资源的授权创建、分页与审计视图，与此前一样仍然缺席。

## 测试

`packages/team/team-admin-api/tests/api.spec.ts` 以控制台驱动它的方式驱动 API，并逐一去掉三道证明中的每一道，检查存储没有发生任何改变。控制台自身的视图没有单元测试；它们渲染的是 API 的答复，它们可以做什么由 API 允许什么决定。
