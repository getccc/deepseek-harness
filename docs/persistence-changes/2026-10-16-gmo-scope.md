<a id="compatibility"></a>
## Compatibility

A new root: no log written before this change holds a `gmo/scope` event, and a log without one is read as `off`, which is what every Session starts as. The event is a whole-value replace whose `selected` arm carries the category reference and the display name the prompt names it by, so replay needs nothing outside the log. A build that predates the event refuses a log carrying it, as the Session envelope requires of any type it does not know; the event is not marked ignorable, because a model that cannot see the scope would answer from the wrong data.
