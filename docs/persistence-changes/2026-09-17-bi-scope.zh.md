<a id="compatibility"></a>
## 兼容性

一个新根：本变更之前写入的日志都不含 `bi/scope` 事件，没有该事件的日志读作 `off`，也就是每个 Session 的起点。该事件是整值替换，其 `selected` 分支携带项目引用以及提示词用来点名它的显示名，因此回放不需要日志之外的任何东西。早于该事件的构建会拒绝携带它的日志，这是 Session 信封对任何它不认识的类型的要求；记录该事件的写入方在后续阶段到来，届时再决定是否把它标记为可忽略。
