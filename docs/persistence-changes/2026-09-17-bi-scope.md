## Compatibility

A new root: no log written before this change holds a `bi/scope` event, and a log without one is read as `off`, which is what every Session starts as. The event is a whole-value replace whose `selected` arm carries the project reference and the display name the prompt names it by, so replay needs nothing outside the log. A build that predates the event refuses a log carrying it, as the Session envelope requires of any type it does not know; the writer that records it arrives in a later delivery and decides then whether to mark it ignorable.
